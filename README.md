# JobAds — агрегатор вакансий с партнёрскими ссылками

Сайт-агрегатор предложений о работе по всей России (jobads.ru): каталог вакансий курьеров, водителей, кладовщиков, мобильных банкиров, клинеров. Монетизация — партнёрские (реферальные) ссылки: Яндекс Еда, Альфа-Банк, Qlean (leads.su).

## Технологии
- **Astro 5** — статическая сборка (`npm run build` → `dist/`, 4000+ страниц)
- Единый источник данных: `src/data/professions.json` (17 профессий, 11 офферов, 226 городов)
- TypeScript, единый дизайн-система в `src/styles/global.css` (светлая/тёмная тема)

## Структура сайта (programmatic SEO, методология autoseo)
- `/` — главная-каталог с фильтрами (Доставка / Продажи / Клининг) и живым поиском
- `/{profession}/` — страница профессии (17 шт.)
- `/{city}/` — страница города (226 шт.)
- `/{city}/{profession}/` — «работа курьером в Казани» (3842 шт.)
- `/professions/`, `/cities/` — списки всех направлений и городов
- `/company/{slug}/` — страницы компаний-работодателей

## Данные
`src/data/professions.json` — вся контентная модель:
- `site` — название JobAds, слоган, поле `erid` (маркировка рекламы)
- `professions` — профессии: тексты, требования, зарплаты, ссылки на отклик
- `offers` — партнёрские офферы: компания, роль, гео, трекинговая ссылка
- `cities` — города России с предложным падежом (`name_in`: «в Казани»)

## Разработка
```bash
npm install
npm run dev       # dev-сервер
npm run build     # статическая сборка в dist/
npm run preview   # предпросмотр собранного
```

## Деплой
Статическая сборка заливается на VPS (nginx, vhost jobads.ru). SSL — certbot после переключения DNS.
